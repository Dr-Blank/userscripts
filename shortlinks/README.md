# Shortlink UserScripts

This folder contains userscripts for getting through ad-gated shortlinks.

## UserScripts

Below is a list of the userscripts available in this folder. Click on the script name to install it.

### [⏱️ Always Focused](./AlwaysFocused.md)

Keeps countdown timers running when you move to another window.

Install: [AlwaysFocused](https://github.com/Dr-Blank/userscripts/raw/main/shortlinks/AlwaysFocused.user.js)

## Installation

To use these scripts, you'll need to install a userscript manager in your browser, such as Violentmonkey or Tampermonkey. Once installed, you can click on the script name above to install it.
